# 验证记录与已知限制

记录日期：2026-10-22。

## 环境与范围

实测环境为 Windows WSL。现有 Hermes v0.22.2，系统 Python 3.14.7。教程的初始化工具仅用标准库，声明支持 Python 3.10+；没有在所有 Python 小版本、原生 Windows 或 macOS 上逐一运行。

本机已有 Hermes 和模型配置。没有为了这份教程重装 Hermes 或申请新付费服务。安装步骤与 Skills URL 方式核对了官方文档及本机命令帮助，不能将这一点说成全新电脑安装已验收。

## 已完成的实测

在仓库之外建立隔离目录，只使用公开的虚构 first_source.txt，未把真实私人 Wiki 作为测试输入。

- 候选提取：独立 Hermes 调用实际读取公开 wiki-review-intake，生成 C01 协作偏好与 C02 尚未开始的计划。未把未采纳的 AI 建议生成用户决定。
- 候选阶段正式页：程序逐字节比较三个正式主题页，结果均未改变。
- 来源归档：实算来源与归档 SHA-256 相同，原字节一致，待导入无练习来源残留。
- 部分批准：第二次独立 Hermes 调用读取公开 wiki-approved-merge 后，仅合并 C01；C02 保持待审。主模型用程序核对，未批准的生活页与当前项目页仍逐字节不变；原始来源不变。
- 版本恢复：合并前创建本地副本，核对可恢复文件存在；没有推送私人练习目录。
- Skill 元数据：三份 Skill 的名称、描述长度、必需章节、可移植路径通过本地检查。
- Word 派生稿：生成后通过 docx 包健康检查，未做页面逐页视觉排版验收。

- 新会话只读检索：第三次独立 Hermes 调用读取 wiki-context-reader 与正式页，答出已批准的协作偏好；对学习笔记是否已经开始，回答正式页不足以确认，没有挪用待审内容。主模型对调用前后全部练习文件计算哈希，结果全部未变。

- 初始化与结构检查：主模型独立重跑 `python3 -B -m unittest discover -s tests -v`，14 项测试通过，实测耗时 3.315 秒；直接检查随仓库分发的模板，返回 `ok: true`。覆盖新建/空目录、拒绝非空与重复初始化、父子目标与符号链接拒绝、缺结构、坏链接、JSON 错误和只读性。

## 不能从测试推出的结论

一次虚构案例通过不保证模型以后永不越权、自动识别全部敏感信息或给出正确的人生建议。Skill 是指引，不是强制权限控制。`check` 不验证事实真伪和隐私完整性。

本仓库没有发布作者的生产采集器、游标、并发锁或调度任务，也没有宣称原系统今天的多来源通知全链路都重新测试过。没有读者耗时统计、节省比例或长期稳定性数据。
