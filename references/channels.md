# 渠道逐步选择

不要一次展示复杂配置表让用户自行猜测；用户选到某渠道时再展示该行并询问下一步。每项均可跳过。连接聊天工具不等于授权 Wiki 读取。

| 选择 | 用途 / 已附实现 | 前提 | 实际兼容与范围 | 选择 |
|---|---|---|---|---|
| 当前对话 | Agent 将用户选定片段写文件，再用 current 导入 | 宿主可读取当前获准片段、写本地文件和运行 Python；确认远端模型许可 | 文件流程本机测试；未跨 Agent 测试；不包含早期会话 | 引导选范围 / 用户自行保存文字 / 跳过 |
| 指定文件 | 单文件原字节归档、hash、候选 | 明确完整文件路径；语义候选要求 UTF-8 文字 | 通用核心本机测试；无目录扫描、OCR、Office、语音或 PDF 文本提取器 | 引导选择文件 / 用户转写另作来源 / 跳过 |
| 微信 | 可选 Hermes 已接收私聊只读采集，或通用 JSONL/手动文件 | 已有网关和授权、准确会话/profile、兼容schema；无Hermes可用导出文件 | 合成SQLite/JSONL测试通过；真实平台接收未验证，不含其他好友/群聊/个人账号登录 | 检查已有适配 / 手动替代 / 跳过 |
| Telegram | 可选 Hermes 私聊/topic只读采集，或通用 JSONL/手动文件 | 已有网关和授权、准确chat/profile/topic、兼容schema | 合成测试通过；真实Bot API接收、云端历史及媒体未验证；无独立实时客户端 | 检查已有适配 / 手动替代 / 跳过 |
| 宿主历史 | 明确范围导出为JSONL/文字；不是通用TUI数据库采集 | 宿主实际导出能力和版本、用户指定会话与窗口 | 无Codex/Claude/Hermes TUI数据库适配；不自动遍历 | 宿主官方导出 / 手动文字 / 跳过 |

## 为什么不能直接提供“万能聊天连接器”

Hermes 的本机微信/Telegram链路若读取 Hermes `state.db`，得到的是该宿主已接入且已保留的消息，不是微信/Telegram全部本地历史。不能将这一路径换个名称便声称独立通用。本候选版重写了可选只读适配和合成测试；无任何生产 chat ID、topic ID、凭据或 OAuth。命令及范围见 [连接器](connectors.md)。

未来适配必须独立交付并测试：精确账号/会话/主题 allowlist、时间边界与时区、角色和撤回过滤、来源消息稳定标识、游标持久化、先归档再前进、跨会话断点恢复、重复运行无新增、不同会话绝不混入、故障后不丢消息。输出仍进入通用 ingest/submit，不得直接写正式知识。

## 模型与自动化是另外两道门

- 当前对话在某模型上可见，不意味着之前的所有历史也允许发送给它；本地模型和远端服务分别确认。
- 若用户限制“本地”，远端 Agent 不可读取正文再声称“核心不联网所以合规”。可指导用户本地运行后仅交付非敏感状态。
- 不要求安装聊天导出器；不指导绕过平台访问控制。导出器可能看到比所选范围更多的账号数据，需要另行审查。
- 文件导入成功不代表定期采集、消息通知或用户实际收到通知。当前提供手动采集与本地待审摘要，没有实施任何 scheduler 或远端 delivery adapter。
